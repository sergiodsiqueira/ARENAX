ARENAX - Guia de Instalacao para TI

Use este guia para preparar uma maquina Windows e instalar ou atualizar a ARENAX a partir de um pendrive, sem internet.

Resumo rapido

O instalador da ARENAX nao instala WSL2 nem Docker Desktop. Esses itens devem estar instalados e funcionando antes de executar o setup.

Pre-requisitos

  • Windows 64 bits com virtualizacao habilitada na BIOS/UEFI.
  • WSL2 instalado e funcional.
  • Docker Desktop instalado, configurado para usar WSL2 e em execucao.
  • Docker Compose disponivel pelo comando docker compose version.
  • Porta HTTP 80 livre, ou outra porta definida pela equipe tecnica antes da instalacao.
  • Espaco em disco suficiente para imagens Docker, banco PostgreSQL e videos de Replay.

Validacao antes do setup

Abra o PowerShell como Administrador e valide:

  1. wsl.exe --status
  2. docker version
  3. docker compose version

Se algum comando falhar, corrija WSL2/Docker antes de executar o instalador.

Instalacao nova pelo pendrive

  1. Conecte o pendrive contendo ArenaX-Setup-vX.Y.Z.exe.
  2. Confirme que o Docker Desktop esta aberto e com status running.
  3. Execute o instalador como Administrador.
  4. Informe nome, e-mail e senha do Proprietario inicial quando solicitado.
  5. Aguarde o instalador carregar as imagens Docker, criar o banco, rodar as migrations e iniciar os servicos.
  6. Abra http://localhost para acessar a ARENAX.

Atualizacao de uma instalacao existente

Ao detectar uma ARENAX instalada, o setup entra em modo atualizacao.

  • Banco de dados, configuracoes, secrets e Replays sao preservados.
  • O instalador carrega as novas imagens Docker a partir do proprio setup.
  • Antes de migrar, o script gera backup do PostgreSQL em ProgramData\ARENAX\backups.
  • A atualizacao e bloqueada se houver Sessao em andamento.

Dados preservados

Por padrao, os dados ficam fora da pasta do aplicativo:

  • ProgramData\ARENAX\postgres: dados do PostgreSQL.
  • ProgramData\ARENAX\media: arquivos de Replay e buffers de video.
  • Program Files\ARENAX\.env: versao, caminhos e secrets da instalacao.

Nao apague essas pastas durante atualizacoes.

Comandos uteis

  • Ver servicos: docker compose --project-directory "C:\Program Files\ARENAX" -f "C:\Program Files\ARENAX\docker-compose.production.yml" ps
  • Parar ARENAX: docker compose --project-directory "C:\Program Files\ARENAX" -f "C:\Program Files\ARENAX\docker-compose.production.yml" down
  • Ver logs da API: docker logs arenax-api-1
