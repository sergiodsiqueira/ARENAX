# Manifesto ARENAX

Nós acreditamos que:
- A tecnologia deve simplificar, não complicar.
- O operador deve olhar para a Arena, não para dezenas de telas.
- Uma Sessão deve contar toda a história de uma utilização.
- Espaços são recursos vivos da Arena.
- Equipamentos existem para servir à operação.
- Momentos registram experiências, não apenas vídeos.
- O Mission Control transmite tranquilidade quando tudo está normal e chama atenção somente quando necessário.
- Toda funcionalidade nova deve tornar a operação mais rápida, segura ou clara.
- Hardware não conhece regras de negócio.
- O domínio independe da tecnologia de implementação.
