# Linguagem Ubíqua

Produto, UX, documentação, API e código devem usar os mesmos conceitos.

## Termos oficiais
Arena, Espaço, Sessão, Cliente, Responsável, Equipamento, AX Device, Momento, Replay, Timeline, Ocorrência, Mission Control e Arena Designer.

## Regras
- Preferir **Sessão** a Agendamento/Reserva para a entidade de negócio.
- Agenda é uma visão temporal das Sessões.
- Não existe entidade Reserva no MVP; a Sessão nasce Agendada.
- Usar **Espaço** inclusive na interface.
- Cliente é o cadastro de quem é atendido pela Arena; Responsável é o papel que um Cliente exerce em uma Sessão.
- Cliente não é Usuário: credenciais e permissões pertencem ao contexto de Acesso e Identidade.
- O botão físico registra acionamento; não “grava replay” diretamente.
- Replay é vídeo; Momento é conceito de negócio.

> **Na ARENAX, tudo acontece em um Espaço durante uma Sessão.**
