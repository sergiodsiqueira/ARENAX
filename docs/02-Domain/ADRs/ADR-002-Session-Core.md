# Sessão como entidade central

## Status
Aceita.

## Decisão
A Sessão é a entidade central do negócio e representa a utilização de um ou mais Espaços durante um período. Pagamentos, Momentos, ocorrências, compartilhamentos e Timeline são contextualizados pela Sessão.

## Consequências
- Mantém a linguagem consistente.
- Reduz acoplamento.
- Deve orientar novas funcionalidades.
