# Mission Control como centro da operação

## Status
Aceita.

## Decisão
O Mission Control será a tela inicial e principal da operação diária. Deve responder “o que está acontecendo agora?”, exibindo Espaços, Sessões ativas, tempo restante, alertas e saúde operacional sem atualização manual.

## Consequências
- Mantém a linguagem consistente.
- Reduz acoplamento.
- Deve orientar novas funcionalidades.
